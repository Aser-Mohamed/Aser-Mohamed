## Featured work

### [Vela Multilingual Keyboard](https://github.com/Aser-Mohamed/vela-multilingual-keyboard)
A drop-in on-screen keyboard component for Vela JS with **English, Arabic, Russian, Spanish, French and German**, a built-in language picker, and automatic round / rectangular layouts. Documented and open source (MIT), modified from the native Vela input method.

### Astral Music
Music streaming app for the Xiaomi Watch S4 with iTunes metadata and a Flask backend on Hugging Face Spaces. Production work includes a Cloudflare Worker proxy, a waitress server, client-side retry logic, and a backend security audit covering SSRF and path traversal. Has its own Vite / React landing page on Vercel.

### HyperGallery
Photo gallery for the Xiaomi Watch S4. Images sync from a Python backend through OTP pairing, then flow through a custom download pipeline into a grid with a pan-and-zoom photo viewer.

### Swift AI
Vela watch app with device pairing and a six-language interface (English, Arabic, German, Spanish, French, Russian), backed by its own server.

### Nova POS
Windows desktop app that combines inventory, point of sale and invoice generation. Electron, React and SQLite, with a dark Apple-inspired interface, five PDF invoice templates, role-based employee accounts and session persistence.
